> *"Daripada bingung terus bedain Kraepelin vs Pauli, kenapa nggak bikin web latihannya sendiri aja?"*

* **The Struggle:** Pas awal nyiapin psikotes, pusing banget bedain **Tes Kraepelin** & **Tes Pauli** 😵‍💫. Latihan manual pakai kertas *print-out* itu ribet, boros kertas, & capek hitung *timer*. Web latihan di internet pun rata-rata tampilannya kaku dan jadul.
* **The Solution:** Nekat bikin web latihan sendiri dari nol! Lengkap dengan UI yang rapi, *interactive cards*, *timer*, *streak counter* 🔥, hingga preferensi kustom (efek suara, arah soal, dll).
* **The Result:** Dari yang tadinya trauma ngeliat deretan angka koran, sekarang latihan malah seru kayak main *game* 🎮✨.
